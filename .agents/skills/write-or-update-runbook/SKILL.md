# Write / Update Runbook

For the target incident, document:
1. detection signals
2. severity classification
3. owner
4. immediate containment
5. recovery
6. validation of recovery
7. customer communication criteria
8. evidence preservation
9. postmortem requirements

Use SEV-1 automatically for cross-tenant exposure, major data loss, or security compromise.

Support/incident steps must avoid raw scientific-data access unless explicitly authorized through break-glass controls.
